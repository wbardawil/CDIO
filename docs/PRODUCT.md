# AI-CDIO: Fractional Executive Operating System

> **Companion strategy doc:** `docs/STRATEGY-2026.md` is the active strategic source of truth. This doc covers product scope and capabilities.

## What It Is

**The methodology operating system for fractional Chief Digital & Information Officers and internal IT leaders.** It turns a 30-file CDIO playbook into interactive, client-aware engines that produce real deliverables — assessments, roadmaps, status reports, QBR decks, board memos, decision packages — in minutes instead of hours.

Built first as a tool the founder uses on his own fractional practice. Validated in parallel with other practitioners and IT directors.

## The Differentiated Promise

> *"ScalePad manages IT inventory. Fortium gives you a fractional CIO body. ChatGPT gives you a generalist. AI-CDIO is the only platform that turns a 30-file CDIO methodology into deliverables in the surfaces you already use — your AI assistant, your client calls, your weekly rhythm. Faster than ChatGPT because it's domain-deep. Better than Fortium because it scales with you. More specific than ScalePad because it's about strategy, not tickets."*

## What Customers Actually Get

- **Stop starting from scratch** — every engagement reuses 80% of the methodology
- **Generated, not written** — monthly status, quarterly review, board memo all drafted from real client data, you edit
- **Cited authority** — every recommendation grounded in a named framework (NIST CSF, CMMI, TOGAF, SAFe, etc.)
- **Predictable cadence** — clients see the engagement roadmap and commitments via a read-only share link

## In Scope (What We DO)

| Capability | What It Means |
|-----------|---------------|
| **Practitioner Workspace** | Multi-client portfolio for fractionals. Single-org for directors. Same data model, different UI. |
| **Assessment Engine** | 5-level CMMI-aligned maturity scoring across 16 modules. Multi-stakeholder, divergence detection, AI-powered Decision Packages. Framework citations on every score (NIST / TOGAF / CMMI / SAFe per module). |
| **Roadmap Engine** | 30/60/90-day, 6-month, 12-month plans. Value/Effort prioritization. Industry adaptation. Financial models + dependencies + governance. |
| **Engagement Manager** | Monthly status reports, QBR decks, board memos, project charters. Generated from client data + AI narrative. Editable in-app. |
| **Engagement Cadence** | Per-client milestone tracker (commitments, target dates, success criteria). Auto-populated from roadmap + status + decisions. **Shareable read-only link** for client visibility — token-based, no portal, no client accounts. |
| **Value/ROI Tracker** | Commitment → delivery tracking. Monthly value dashboards. Renewal-ready ROI proof. |
| **Templates Library** | Vendor evaluations, M&A tech DD, risk registers, governance frameworks, stakeholder comms matrices. |
| **Knowledge Reuse** | "I solved this at Client A" → suggested for Client B. Cross-client learning per practitioner. |
| **MCP Server** | Expose every engine as MCP tools so practitioners can call them from Claude.ai, Cursor, Codex, or any MCP-compatible AI surface. |

## Out of Scope (What We DON'T Do)

| Boundary | Why |
|----------|-----|
| Implementation services | We advise + deliver artifacts. We don't configure systems. |
| Sell vendor products for commission | Our value is objectivity. Never become a sales channel. |
| Replace MSP infrastructure management | We complement MSPs, not compete on tickets/ops. |
| Legal/compliance certification | We flag risks. Professionals certify. |
| Replace human judgment | We present data + AI recommendations. Practitioners decide. |
| Co-branded client portal (Phase 4+) | High maintenance, low signal. Cadence Share replaces it for now. |
| Direct-to-SMB sales | Practitioner-first. SMBs reached indirectly via practitioners. |
